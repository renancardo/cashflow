# Templates

Page-level layout scaffolds without real data. Templates define regions and spacing — placeholders stand in for live content.

Examples to add as screens land:

- App shell with sidebar and header strip
- Settings section with form groups
- Transactions filter bar + empty table frame

See [ADR-007](../../../../docs/decisions/ADR-007-storybook-vitest.md) for the full taxonomy.
