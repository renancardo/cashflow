# Atoms

The smallest building blocks of the Paper UI. Atoms have no layout responsibility beyond their own box and never import other Cashflow components.

**Current atoms:** `Button`, `Chip`, `Indicator`, `Label`, `MoneyAmount`, `FormattedDate`, `Tooltip`

**Rules**

- Format money and dates through `@cashflow/core` — never hardcode locale strings.
- Use CSS Modules and Paper tokens from `tokens/paper.css`.
- Keep atoms stateless and presentational.

See [ADR-007](../../../../docs/decisions/ADR-007-storybook-vitest.md) for the full taxonomy.
