# Molecules

Simple combinations of atoms that work together as a single unit.

**Current molecules:** `CalendarDayCell` (day number + indicator dots)

Molecules may import atoms from `../atoms/` but should not reach for organisms or app-level data hooks.

See [ADR-007](../../../../docs/decisions/ADR-007-storybook-vitest.md) for the full taxonomy.
